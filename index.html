Cloud Sync (Supabase)

One-time setup (takes ~3 minutes):

  1. Go to supabase.com and create a free account
  2. Click New Project → name it anything (e.g. "pentagon-tracker") → set a database password → create
  3. Once ready, go to SQL Editor → New query → paste this and click Run:
create table deals (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);

-- Allow full access with the anon key (private personal use)
alter table deals enable row level security;
create policy "Allow all" on deals for all using (true) with check (true);
  1. Go to Project Settings → API
  2. Copy the Project URL and the anon public key
  3. Paste them below and click Connect

Once connected, every deal you add or delete is saved to the cloud automatically. Open the same tracker on your phone or another PC and it will load the same data. Your keys stay in this browser only — they are never sent anywhere except Supabase.
